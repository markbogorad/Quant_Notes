# Brownian Bridge
- Basically interpolating data by having there be a [[Brownian Motion aka Weiner Process]] in between
- Periodic vol is consistent with something like returns because it uses the brownian motion
- Correlation structure can be preserved
	- Geometric random walks can be correlated with other series
		- [[Cholesky Decomposition]]
- Can make things differentiable
- Can make it intentionally skewed an play around with other moments
