# Comparative and Screening
### Comparative
- Comparing 2 or more groups or datasets -> "is there a significant difference between these two?"
- Means: T test ([[T Statistic]]) used for comparing means of 2 groups. ANOVA (analysis of variance) when comparing the means >2 groups.
- Variances: F-test compare variances between groups. Levene’s Test Checks across multiple groups.
	- F test also tests if 2 variances are equal to each other -> if ratio of Fs falls within bounds they are statistically the same
- Proportions: [[Chi-squared Distribution]] test used to compare categorical variables, e.g. proportions of people in different categories
- Box plots, dot plots, bar charts
### Screening
- Screen most important variables in a dataset
- [[Dimensionality Reduction]]
	- [[PCA]]
