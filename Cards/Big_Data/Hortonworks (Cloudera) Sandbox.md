# Hortonworks
- Built a distorted version of [[Hadoop (Apache)]]
- Hortonworks is to Hadoop like **Ubuntu is to Linux**
## Why Not Just Use Apache Hadoop Directly?
Because Apache Hadoop is **modular and raw** — setting up a full Hadoop stack from scratch is:
- Complex
- Time-consuming
- Easy to misconfigure

**Hortonworks simplifies this** by:
- Bundling everything together (like a Hadoop “distribution”)
- Adding management tools [[Ambari + Hue]]
- Pre-configuring everything in a downloadable sandbox
