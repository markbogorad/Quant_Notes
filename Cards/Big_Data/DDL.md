# DDL Data Definition Language

> Used to define or **alter the structure of the database** (tables, schemas, indexes, etc.)

|Common DDL Commands|
|---|
|`CREATE` – Create tables or schemas|
|`DROP` – Delete tables|
|`ALTER` – Modify table structures|
|`RENAME` – Change table or column names|

DDL modifies the **schema,** not the data inside.
