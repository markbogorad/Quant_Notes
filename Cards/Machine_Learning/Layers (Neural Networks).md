# Layers
- A group of [[Neurons]] that process input together running in parallel
- Like a step in an assembly line
- Input layer
	- Takes in raw data (e.g. pixel values, text embeddings)
	- Just passes input
- Hidden layer
	- Do the main computation — can be 1 or many.
	- Called "hidden" because you don't really supervise them
	- Can still edit and importantyl freeze these 
- Output Layer
	- Produces the final result (e.g. class label, price)
