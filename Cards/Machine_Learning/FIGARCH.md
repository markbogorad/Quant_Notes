# FIGARCH
$$h_t = \omega + \left[1 - \beta(L)\right]^{-1} \left[1 - \phi(L)\right] \varepsilon_t^2$$
- Long memory of shocks
	- Past shocks have a slow, decaying effect on current volatility. It is useful for modeling **persistence** in financial time series.
