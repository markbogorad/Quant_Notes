# Optimization and Regression
### Optimization
- Finding the best solution to something
	- Unconstrained Optimization: No restrictions on values that variables can take
	- Constrained Optimization: The solution must satisfy a set of constraints
	- Linear and Nonlinear Optimization: Based on whether the objective function and constraints are linear or nonlinear.
	- Global vs Local Optimization: Global optimization aims to find absolute best solution, while local optimization may find a solution that is optimal within a smaller region
### Regression
- [[Regression]]
	- Simple Regression: A linear regression with one independent variable.
	- Multiple Regression: A linear regression with more than one independent variable.
	- Linear Regression: simplest form of regression where relationship between independent and dependent variables is assumed linear.
	- Nonlinear Regression: When the relationship between variables is more complex and cannot be captured by a straight line.
	- Polynomial Regression: Linear regression where relationship modeled as nth-degree polynomial.
	- Logistic Regression: Although technically a classification algorithm, it is often included in regression discussions because it predicts probabilities and is used for binary outcomes.
- Simple [[OLS Estimator]] is most popular
