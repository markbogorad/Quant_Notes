# Root Finding
- Root finding is essentially looking for values of x where $f(x)=0$. In a literal sense, this is graphically looking for places where you touch the x axis
	- Ex: in [[Implied Volatility]], you're looking to make the Black-Scholes price match the observed market price
- Specific numerical methods are used when there is no closed form solution, these are
	- [[Bisection Method]]
	- [[Secant Method]]
	- [[Newtons Method]]
	- [[Brent Method]]
